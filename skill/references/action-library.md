# 角色动作表演库（动作拆解范式）

写动作时**不要只写一个动作名词**（"侧踢""拔剑"），要把动作拆成四层，镜头才立得住：

> **预备姿势 → 发力瞬间 → 接触/命中 → 收尾反应**

每一层都要带：重心在哪、肩胯怎么转、呼吸节奏、视线落点、次要身体部位（手指/脚趾/喉结）的小动作，以及衣料/发丝/雨水/尘土的物理反馈。

## 1. 通用微动作 / 表情 / 情绪（带拆解）

### 指尖摩挲
- 预备：拇指指腹搭在食指第二节；
- 发力：指腹缓慢来回蹭过指节，像在磨一颗不存在的珠子；
- 收尾：指尖一停，轻轻按下去。
- 配套表情：眼垂着，不看人。

### 攥拳蓄力
- 预备：五指张开悬在身侧，肩微抬；
- 发力：从小指开始依次内扣，指节一根根绷紧，手背青筋浮起；
- 接触：拇指最后压在食指外侧，指甲掐进虎口；
- 收尾：整条小臂肌肉绷成一条线，呼吸压到最浅。

### 垂眸敛目
- 预备：视线平视；
- 发力：眼皮缓慢下压，睫毛在颧骨投下一道影，眼球顺势下移；
- 收尾：停在半垂不垂的位置，睫毛轻颤一下。

### 喉结滚动
- 预备：脖颈微僵；
- 发力：喉结从下往上滑一次，又沉回去；
- 收尾：吞咽完，牙关轻轻咬合。

### 脚步踉跄
- 预备：重心前倾过多；
- 发力：前脚掌一滑，脚踝外翻；
- 接触：另一只脚慌忙踩稳，膝盖屈了一下卸力；
- 收尾：手扶住墙/柱子，掌心按出一个湿印。

## 2. 近身搏斗动作（四层拆解示范）

### 直拳冲击
- 预备：后脚蹬地，胯先转，肩跟着送，拳头从腰侧沿直线冲出，另一肘自然夹在肋侧；
- 发力：肩完全送出去的瞬间拳峰接触目标，指节绷紧；
- 接触：拳面命中的刹那，目标皮肤凹陷，衣襟被拳风压得贴肉；
- 收尾：拳头不停，沿原轨迹收回护到下颌，重心立刻回正，呼吸从鼻子短促喷出。

### 勾拳摆拳
- 预备：重心压到后腿，拳心朝上从腰侧起弧，肩下沉；
- 发力：腰胯横向一转，拳走弧线，肘抬到与肩平；
- 接触：拳峰擦过对方下颌/软肋，布料被带得一甩；
- 收尾：拳头顺势停在自己下巴前，眼睛始终盯着对方眼睛。

### 侧踢横扫
- 预备：重心整个移到支撑脚，后腿膝盖先屈起、大腿抬平，脚尖勾起，同侧手向后摆维持平衡，肩下沉；
- 发力：胯部先向前送，大腿带动小腿，膝盖从屈到弹直，气从牙缝里嘶地喷出；
- 接触：脚面/胫骨正中目标（手腕/膝弯/肋侧），皮肤随受力凹下去半寸，目标被带得横移；
- 收尾：小腿顺势摆过，落地时前膝微屈缓冲，手臂收回到护脸位，呼吸立刻压回去。

### 格挡卸力
- 预备：小臂斜抬到额前，肘夹紧，掌心朝外来；
- 发力：接触瞬间小臂不硬接，而是顺着对方力道往侧面一引；
- 接触：手腕一旋把攻击带到自己外侧；
- 收尾：身体借势转半圈，脚下滑出半步重新站定。

### 翻滚闪避
- 预备：屈膝、低头、下巴扣到胸口；
- 发力：肩先着地，后背、腰、胯依次滚过，手在身侧轻推一把加速；
- 接触：后背蹭过地面/积水，溅起一圈水；
- 收尾：蹲姿起身，一只手已经按在刀柄上，眼睛始终没离开对手。

## 3. 兵器动作（四层拆解示范）

### 长剑突刺
- 预备：后手把剑柄贴到腰侧，前手虚搭剑格，剑尖微微下垂；
- 发力：后脚蹬地，胯前送，肩顺着送出去，手臂沿直线完全打直；
- 接触：剑尖先点到目标前一寸，再顺势送进半寸，剑脊震出一声嗡鸣；
- 收尾：手腕一翻，剑尖斜斜下压，立刻抽回胸前。

### 挥剑劈砍
- 预备：剑举过头顶，手腕内旋，剑尖朝后上方，重心压后腿；
- 发力：腰先转，肩跟着压下来，剑走弧线劈下，衣袂被带得向后飞；
- 接触：刀刃砍中目标/劈空斩进空气，剑风把雨珠劈开一道线；
- 收尾：剑顺势沉到身侧，手腕一转收住，不让剑继续晃。

### 反手拔剑
- 预备：右手反握剑柄，拇指轻轻顶开剑格，肩微沉，眼睛不看剑；
- 发力：手腕一翻，剑从鞘里滑出半尺，剑身在鞘口蹭出一声铮鸣；
- 接触：剑完全出鞘的瞬间，手腕一转，剑尖斜斜指向对方咽喉，雨珠挂在剑脊上；
- 收尾：拇指压在剑格上，呼吸停半拍，肩线绷成一条直线。

### 收剑入鞘
- 预备：剑尖下垂，手腕放松，另一只手摸到鞘口；
- 发力：手臂沿直线把剑送回去，眼睛看着对方而不是看剑；
- 接触：剑格"咔"一声卡到鞘口；
- 收尾：手自然垂回身侧，肩松下来，呼吸才重新吐出来。

## 4. 异能 / 法术动作（四层拆解示范）

### 掌心能量汇聚
- 预备：手掌摊开朝前，五指微张，肩沉下来；
- 发力：掌心先亮一点，光从指缝里往外溢，空气被烤得微微扭曲；
- 接触：能量团稳定在掌心三寸，光把下半张脸照亮；
- 收尾：手腕一送，能量团脱手飞出，掌心还留着一点余光。

### 指尖电光缠绕
- 预备：食指中指并拢，其他三指弯曲；
- 发力：蓝白色电弧从指尖跳出来，噼啪响，顺着指节往上爬；
- 接触：电弧在两指间织成一张小网，照得瞳孔发亮；
- 收尾：手指一握，电弧"啪"地收进掌心。

## 5. 表情五官拆解卡（禁止用抽象情绪词）

**铁律：分镜里不许出现"悲伤/愤怒/开心/委屈/紧张/震惊/决绝/复杂"这类情绪词。** 情绪词只给你自己在设计时用，写进分镜的必须是五官在时间线上的具体变化。

每张卡按 **0.3–1.5 秒** 的表演时间线写：先动哪块肌肉、再动哪块、最后停在哪。直接挑一张卡，把动作顺序抄进分镜。

### 惊（被袭击/意料之外）
1. 眉毛先抬——眉心展开，眉尾向上挑，额头挤出浅横纹；
2. 上眼睑跟着抬起，眼睛睁大，虹膜上下露出一圈眼白；
3. 下颌松半分，嘴唇微张但没出声；
4. 整脸僵住 0.2 秒，只有眼睫颤一下。

### 怒（压着的火，不是爆发）
1. 眉心先锁——两条眉往下压、往里挤，眉心挤出一道竖纹；
2. 眼睛从平视变成盯住，眼白变少，瞳孔定住不动；
3. 鼻翼翕动两下，像在闻什么；
4. 后槽牙咬紧，腮帮子咬出一条硬棱，下颌线绷成一条直线；
5. 呼吸从鼻孔变粗，但肩没动。

### 悲（忍着不哭，不是号啕）
1. 眉心先向中间上方抬，两眉尾微微往下挂成八字；
2. 上眼睑下垂，眨眼速度变慢，眼睫在颧骨投下影；
3. 嘴角下拉，下颌微微抖了一下，又被咬住；
4. 喉结上下滚一次，把到嘴边的东西咽回去；
5. 一滴泪从外眼角先滚出来，顺着鼻梁侧滑，不抬手擦。

### 惧（被刀/被枪指着）
1. 眼睛先定住不动，瞳孔放大；
2. 血色从脸上退下去，唇色变浅；
3. 嘴唇干，舌尖无意识舔了一下下唇；
4. 喉结用力滚一次，咽了口唾沫；
5. 肩向后缩半寸，背微微弓起来。

### 冷笑 / 不屑
1. 单侧眉毛极轻地挑一下，另一边不动；
2. 同侧嘴角先向上扯起半分，对侧纹丝不动；
3. 从鼻孔里出半口气，像嗤了一下；
4. 眼皮半垂，眼神从眉毛底下斜斜看过来；
5. 头微微偏一边。

### 隐忍 / 压抑情绪
1. 嘴角先绷平，嘴唇抿成一条线；
2. 下颌线收紧，咬肌鼓一下又平下去；
3. 眨眼速度变慢，眼神定在一点上不飘；
4. 眼睫极轻地颤一下；
5. 呼吸从鼻孔缓慢、长长地吐出来。

### 决绝 / 下了决心
1. 下巴先微微抬半分，脖子拉长；
2. 眼皮半垂，不再躲闪；
3. 视线定在对方眼睛上，一眨不眨；
4. 嘴唇抿成一条直线，嘴角向下压；
5. 肩线从微耸放平，整个人沉下去。

### 心动 / 柔软下来（反转戏用）
1. 眉心先松开，原本锁着的眉展开；
2. 眼神从锋利变柔，瞳孔微微放大；
3. 嘴角极轻地动一下，不到笑的程度，只是松了半分；
4. 呼吸从浅变深，胸口轻轻起伏一次；
5. 眼睫垂下，又抬起来。

### 痛 / 受伤
1. 眉心猛地挤在一起，双眼瞬间紧闭；
2. 嘴角向一边抽了一下，没喊出来；
3. 呼吸被截断半拍，从齿缝里嘶出一口气；
4. 眼皮抖了好几下才睁开；
5. 受伤口附近的肌肉不自主地绷住。

## 6. 怎么用这些卡

- 写分镜时**先选情绪（自己心里知道就行）**，再从对应卡里挑 3–5 个动作，按时间线写进镜头；
- 不要整张卡全抄，挑和镜头时长匹配的部分：2 秒镜头写 2–3 个动作，4 秒镜头写 4–5 个；
- 同一角色相邻两镜表情必须有**变化**，不能两镜都是"面无表情"；
- 反应镜头（对方在说话、主角在听）单独给一镜时，必须用一张完整的表情卡。

## 7. 反面例子（禁止这样写）

- ❌ "她很悲伤地看着他" —— 抽象情绪词；
- ❌ "他愤怒地一拳砸下去" —— "愤怒"是评价；
- ❌ "她露出惊讶的表情" —— 空洞；
- ❌ "表情复杂" —— 什么都没说。

✅ "她眉心先向中间上方抬，两眉尾往下挂成八字；上眼睑下垂，眨眼慢了半拍；嘴角下拉，下颌抖了一下又咬住；一滴泪从外眼角滚出来，她没抬手擦。"

## 8. 动作描写必带的次要细节（每镜至少挑 2 个）

光写主动作不够，还要带这些让画面活起来：

- **重心**：压在哪只脚、膝盖屈到什么程度、身体前倾还是后仰；
- **肩胯**：肩有没有送出去、胯有没有转、肩线是平的还是一高一低；
- **呼吸**：是屏住、是从牙缝嘶出、还是短促喷出；
- **视线**：眼睛盯在哪——对手眼睛、攻击来向、自己的手、还是根本不看；
- **手指/脚趾**：指节有没有响、脚趾有没有抠进鞋底；
- **衣料/发丝/雨水**：袖子被风灌起来、发丝贴在汗湿的额角、雨珠顺着下颌滑下、衣摆在转身时甩出一个弧；
- **环境反馈**：脚下水被踩出一圈涟漪、灰尘从脚边腾起、影子在墙上晃。
