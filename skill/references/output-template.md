# 输出模板与交付前自检清单

## 1. 标准输出模板（每一段都按这个格式）

```
【视频 X】
场景描述: 时间、地点、空间布局、光线方向、天气、关键道具、地面/墙面细节、整体氛围（完整独立写满，禁止"同上"）
角色: 出场角色名 + 本镜可见的外形关键件（服装/武器/伤口）
道具: 画面出现的关键道具
风格要求: 本次段风格关键词 + 剪辑节奏（硬切为主 / 动作匹配切为主 / 允许叠化）+ 画幅

【00-XX 秒】: [衔接：硬切/动作匹配/叠化] 景别，机位高度+角度，焦段+景深，运镜，构图（主体在画面哪侧、占比、前景遮挡）。画面内容，角色具体动作，表情情绪。台词/独白。视觉特效。环境音效。动作音效。
【XX-XX 秒】: ……
……
```

## 2. 写作示范（一段 15 秒 2.0 片段样例）

```
【视频 1】
场景描述: 深夜，废弃地下停车场，水泥柱上渗水，头顶日光灯两明一灭，冷白光打在潮湿地面拉出长条反光，远处通风口百叶窗漏出一点绿，空气里浮着尘土。
角色: 林夜（黑衣短发、左耳一道旧疤）、阿鬼（刀疤脸、皮夹克、右手缠白布）
道具: 一根生锈铁管
风格要求: 电影写实，冷青色调，2.35:1，剪辑节奏：动作匹配切为主，关键重音硬切

【00-03 秒】: [硬切入] 远景，低角度贴地，24mm 广角深景深，固定，构图：林夜在画面右三分线，前景是虚化的水洼反光。他从水泥柱后一步踏出，靴底碾过碎玻璃，肩背绷紧。环境音：通风口低频轰鸣。动作音：玻璃咯吱碾碎。
【03-06 秒】: [动作匹配] 中近景，过阿鬼右肩，50mm 标准浅景深，固定，构图：林夜在画左被肩背虚化框住。阿鬼从阴影里站直，右手缓缓摸向腰间匕首，嘴角扯出冷笑。环境音：水滴回声。动作音：皮夹克摩擦。
【06-08 秒】: [硬切] 特写，平拍 85mm 长焦浅景深，急推，构图：林夜左眼占画面 1/3，焦点锁瞳孔。他瞳孔微缩，下颌线绷紧，喉结轻滚。林夜内心独白: 来了。（无口型，画外音）视觉特效：轮廓光勾出半张脸，睫毛在颧骨投下细影。
【08-11 秒】: [动作匹配] 中景，手持 35mm 广角，跟拍，构图：阿鬼从画左冲出，动作拖尾。他拔刀横斩，林夜侧身让过，刀风剪断一缕发丝。环境音：空气被撕裂的嗡鸣。动作音：刀刃破空、发丝断裂。
【11-15 秒】: [硬切重音] 近景，斜角 50mm，甩镜后定格，构图：林夜反手夺棍抡出，铁管在画面中央砸下。铁管正中阿鬼小臂，阿鬼吃痛后仰撞在水泥柱上，碎灰簌簌落下。视觉特效：冷白灯晃了一下，灰尘在体积光里翻涌。环境音：远处警笛。动作音：金属骨骼闷响、铁管破风、身体撞柱。
```

## 3. 交付前自检清单（逐条过，任何一条不过就改完再交）

1. 剧情 100% 贴合原文，无删减、无篡改逻辑；
2. 片段时长、镜头数精准匹配版本（2.0：15s/5–6 镜；2.5：30s/10–12 镜）；
3. 每段开篇场景描述完整独立，无"场景同前"；
4. 每镜八要素齐全：景别、机位高度+角度、焦段+景深、运镜、构图与主体占比、动作、表情、特效、音效（环境+动作）；
5. **衔接检查**：相邻镜动作方向一致、视线方向匹配、180° 轴线不穿帮、景别跨一档以上、切点符合用户选的剪辑节奏（硬切/动作匹配/叠化）；
6. 长台词按字数表拆镜，景别交替；
7. 独白标注"无口型、画外音"，第一人称；
8. **动作四层拆解**：每个关键动作都写齐"预备姿势 → 发力瞬间 → 接触/命中 → 收尾反应"，并带至少 2 个次要细节（重心/肩胯/呼吸/视线/手指/衣料发丝雨水），禁止只写"他踢飞刀""她拔出剑"这种动作名词；
9. **表情禁抽象词**：分镜里禁止出现"悲伤/愤怒/开心/委屈/震惊/决绝/复杂"等情绪词，必须按 `references/action-library.md` 的"表情五官拆解卡"把情绪翻译成眉毛/眼睛/嘴/下颌在时间线上的具体动作；
10. 格式统一、纯文本、可整段粘贴进 AI 视频生成器。

## 4. 交付语气

分镜正文之后只加 1–2 行说明：
- 共 N 段 × 时长；
- 建议参数（若用户要 2.0 参数，去 `seedance-params.md` 拿）；
- 哪几镜如果生成不稳，建议加参考图或首尾帧。
