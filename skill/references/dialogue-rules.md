# 台词与独白规范

## 1. 字数硬上限（按镜头时长）

| 镜头时长 | 台词上限 | 独白上限 |
|---|---|---|
| 2 秒 | ≤ 6 字 | ≤ 8 字 |
| 3 秒 | ≤ 9 字 | ≤ 12 字 |
| 4 秒 | ≤ 12 字 | ≤ 16 字 |

超过字数 = 必须拆成多个镜头，同时穿插景别交替（近景 → 特写 → 过肩 → 近景）。

## 2. 格式标准（严格照抄）

**人物台词**：
```
角色名说:「台词内容」
```
- 必须用中文直角引号「」，不要用 "" '' 『』。
- 多人对话必须明确写说话人，不能只写台词。

**内心独白**：
```
角色名内心独白: 独白内容
```
- 标注：**无口型、画外音、嘴部无动作**。
- 必须第一人称，贴合当下动作与情绪。

## 3. 拆分规则

- 一句超长台词禁止单镜硬塞，拆成多镜 + 景别切换。
- 例："我从来没有相信过你" 共 9 字，可拆为
  - 镜 1（近景，3 秒）：她垂眸说:「我从来没有——」
  - 镜 2（特写，2 秒）：抬眼，声音发颤:「——相信过你。」
- 对话双方必须在每个说话镜头里都能看出是谁在说（正反打 / 过肩 / 名字标注）。
