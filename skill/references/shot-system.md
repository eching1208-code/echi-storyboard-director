# 镜头体系与时长规范

## 1. 版本时长与镜头数量（硬指标，不可错）

### Seedance 2.0
- 单片段总时长：**15 秒**
- 单片段镜头数：**5–6 镜**（按节奏弹性）
- 节奏：高燃打斗 2–3 秒短镜；抒情对话 3–4 秒长镜。

### Seedance 2.5
- 单片段总时长：**30 秒**
- 单片段镜头数：**10–12 镜**（按节奏、信息密度弹性）
- 节奏：打斗快节奏用 2–3 秒短镜；情绪/对话慢节奏用 3–4 秒镜头，可补空镜、反应镜稳节奏。

## 2. 镜头时间标注铁律

- 每镜必须写**精准时间区间**，例如 `【03-06 秒】`，全段首尾相接、不留缝不重叠。
- 每段开篇必须写**完整独立场景描述**（时间、地点、空间布局、光线、天气、道具、氛围），禁止"场景同前""同上"。
- 双人对话必须正反打切换，特写 → 过肩 → 近景交替，**禁止单镜头贯穿全程**。
- 无台词、无独白的纯氛围/空镜镜头，时长严格 ≤ 3 秒。

## 3. 景别体系（必选其一）

特写、近景、中近景、中景、中全景、全景、远景、航拍、主观视角、上帝视角。

## 4. 拍摄方式与机位

**禁用"横屏/竖屏"这种表述**——画幅在段级参数里给，镜头行里不写。

- 基础拍摄：固定、手持抖动、延时、慢动作、高速、定格、微距
- 机位高度：**贴地 / 低角度 / 齐胸 / 过肩 / 俯拍 / 顶拍 / 高角度**
- 机位角度：平拍、仰拍、斜角、鱼眼、超广角
- 叙事拍摄：正反打、过肩、跟拍、环绕、推轨、甩镜

## 5. 镜头细化五要素（每镜都要写进画面描述）

光有景别和运镜不够专业。每镜画面里必须能看出：

1. **焦段/光学感**：
   - 长焦压缩（85mm+，背景压扁、人物突出）
   - 标准焦段（50mm，人眼感）
   - 广角/超广角（24mm，空间拉伸、近大远小）
2. **景深**：浅景深（背景虚成光斑）/ 深景深（前后都清楚）。
3. **构图**：主体在画面哪一侧（左三分线/右三分线/正中/头顶留白压得很低）；前景有没有遮挡物（窗框、雨丝、虚化肩背）。
4. **主体占比**：脸占画面 1/3（特写）、上半身占 2/3（中近景）、全身入画（全景）。
5. **焦点**：焦点锁在眼睛、剑尖、道具还是背景；rack focus（焦点从 A 转到 B）。

## 6. 运镜术语（每镜必选一种或组合）

推镜、拉镜、摇镜、移镜、跟拍、环绕、升降、甩镜、希区柯克变焦、定格、固定、正反打、过肩、斜角、越轴、穿梭、子弹时间、盗梦空间。

## 7. 画面衔接铁律（决定"跳不跳戏"，违反必返工）

### 7.1 动作匹配剪辑（最常用）
- 把一个连续动作**在进行中切开**：上一镜做到一半，下一镜接后半段。
- 例：上一镜"他抬脚踢到半空"，下一镜"脚尖正中对方手腕"。**不要**上一镜动作做完、下一镜从零重新做。
- 切点选在动作**加速度最大**的那一瞬间（踢到、挥中、拔出），最无感。

### 7.2 视线匹配
- 角色上一镜看向画面右侧，下一镜对方必须从**画面左侧**入画或在左侧被看（建立 180° 轴线）。
- 不要上一镜看右、下一镜对方还在右，否则观众会觉得"他在看空气"。

### 7.3 180° 轴线（双人对话/对峙）
- 两个角色之间画一条假想线，摄像机**始终待在同一侧**。
- A 永远在画面左、B 永远在画面右（或反之）；切正反打时不能跳到线另一侧。
- 要换边必须用一个中性镜头（正面、空镜、过顶）过渡，不能硬跳。

### 7.4 运动方向匹配
- 角色朝画面右侧跑，下一镜继续从左往右跑；不要突然从右往左。
- 车、马、雨丝、抛物体的轨迹方向跨镜一致。

### 7.5 出画入画
- 角色走出画面右边缘，下一镜从另一镜的**左边缘**入画，方向感才对。

### 7.6 景别递进
- 相邻两镜景别必须**拉开一档以上**（如中景→特写 OK，特写→近景就太近了容易跳）。
- 不要连续两镜同级景别对切。

### 7.7 切点选择（对照用户在引导阶段选的剪辑节奏）
- **硬切**：直接切。用在动作击中、对话节拍点、悬念停顿后。
- **动作匹配切**：上一镜动作进行到 2/3 处切，下一镜接动作完成。**动作戏默认首选**。
- **叠化 / 淡入淡出**：时间跳跃、回忆、梦境、抒情。动作戏**不要**用。
- **甩镜切**：上一镜末尾镜头快速甩动，下一镜从甩动中稳下来，用于激烈转场。
- **闪白 / 黑场**：段落结束、情绪重击、时间大跳。

## 8. 单镜写法硬性组合

每一镜必须同时写齐：

> **时间区间 + 景别 + 机位高度/角度 + 焦段/景深 + 运镜 + 构图与主体占比 + 画面内容 + 角色动作 + 表情情绪 + 台词/独白 + 视觉特效 + 环境音效 + 动作音效 + 与上一镜的衔接方式（硬切/动作匹配/叠化）**

缺一不可。禁止只写"特写，他看着她"这种空心镜头。

## 9. 节奏分配参考

| 段落情绪 | 单镜时长 | 景别偏好 | 衔接偏好 |
|---|---|---|---|
| 打斗/追逐/高潮 | 2–3 秒 | 近景、特写、跟拍、甩镜 | 动作匹配切、硬切 |
| 对话/抒情/对峙 | 3–4 秒 | 过肩、正反打、缓慢推拉 | 硬切为主，重音处切 |
| 转场/空镜/反应 | 1.5–3 秒 | 远景、空镜、特写物件 | 叠化或硬切皆可 |
