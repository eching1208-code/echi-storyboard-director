# Seedance 2.0 高级生成参数体系

仅当用户用 **Seedance 2.0** 生成、或明确问"参数怎么配""参考图权重""正负向词"时打开本文件。2.5 用户不需要这些。

## 1. 必填生成参数

- 生成模式：**全能参考**
- 首尾帧图：无 / 按用户指定场景描述自定义
- 种子值：单镜头固定数值；**同一场景内相邻镜头用相近种子值**，保证画面统一。

## 2. 参考图权重策略（给建议时直接给数字）

| 参考图类型 | 建议权重 | 作用 |
|---|---|---|
| 角色参考图 | **0.8** | 锁定面部、发型、人物特征 |
| 场景参考图 | **0.7** | 锁定空间结构、光影方向 |
| 风格参考图 | **0.5** | 统一画面色调、电影质感 |

## 3. 正向 / 负向提示词

### 正向词结构
> 主体动作 + 环境场景 + 镜头语言 + 光影质感 + 电影术语 + 画质质量

常用电影术语（可直接塞进正向词）：
- `anamorphic lens` 变形宽银幕
- `shallow depth of field` 浅景深
- `volumetric lighting` 体积光
- `film grain` 胶片颗粒
- `rack focus` 焦点转移

### 负向词通用库（每次都带上）
```
畸形手指, 多余肢体, 模糊, 低画质, 水印, 文字, 面部扭曲
```

## 4. 成片标准参数

- 分辨率：**1080p**
- 帧率：**24fps**
- 画面比例：**2.35:1**（横屏电影感）
- 单条生成：**5 秒**
- 选片：**4 选 1 最优**

## 5. 怎么把参数写给用户

不要把这一整节都甩给用户。用户要参数时，按当前这段分镜给一段浓缩版，例如：

> 建议参数：生成模式=全能参考｜参考图：林夜角色图×1（权重 0.8）、停车场场景图×1（权重 0.7）｜正向词：anamorphic lens, shallow depth of field, volumetric lighting, film grain｜负向词：畸形手指,多余肢体,模糊,低画质,水印,文字,面部扭曲｜1080p / 24fps / 2.35:1。
